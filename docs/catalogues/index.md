# Catalogue research — the archive behind the Promotion Catalogues pages

Every [[../databases/promotion-catalogues|Promotion Catalogues]] page (a Thai reading page per merchant per month) rests on web research into what each bank, network, wallet and merchant offers that month. The research is kept here rather than thrown away after the page is written, so next month's run starts from it. The same campaign turns up on several pages, renews under a new code, or gets picked up by the [[../concepts/promotion-bureau|Promotion Bureau]] (user, 2026-10-01: "Make documents somewhere in case we can just easily find it next time since they might be connected in some ways in the future").

## What's here

- [[campaigns]] — **campaign lineage**: every campaign met so far, by issuer. Each has its predecessor → successor chain (NW3 → NW4, MR1 → HY1, BMG → BGO, EPW538 → SPW796, KFVSEP → KFVOCT …), the pages it's on, and where the household tracks it. **Start here each month.**
- [[research-methods]] — how each site can be read. It covers which ones need headless Chrome, which have a JSON index, Shopee's captcha, and where tier tables hide in posters.
- **Monthly research reports**, as the researchers wrote them, with every tier, cap, date and source URL. Each is marked verified, third-party only or unverified.

## Each month

1. Open [[campaigns]]. For every row that **ended** look for its successor, and for every row that **continues** check the end date. Re-check every **not published yet** row.
2. Research the merchants **and** the offers that name no merchant. Read the sites as [[research-methods]] says.
3. Save each researcher's report here as `YYYY-MM/<topic>.md`. Add the new rows and chains to [[campaigns]], and record any new site trick in [[research-methods]].
4. Keep private things out: **no one's reward-points balance** goes in a report or on a page.
