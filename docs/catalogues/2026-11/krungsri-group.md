## 11. New site tricks (for `research-methods.md`)

- **GO Wholesale publishes Krungsri campaigns before krungsricard.com does.** SU1/SU2 (`kcc-cashback-nov26`) was on GO's WordPress list on 31 Oct and absent from Krungsri's listing JSON on 1 Nov. Query it in headless Chrome with a search term: `centralfoodwholesale.co.th/wp-json/wp/v2/promotions?per_page=100&search=กรุงศรี` (URL-encoded) — `--dump-dom` returns the JSON inside a `<pre>`; or `?promotion_category=124&_fields=slug,date,title` for every credit-card post. The full T&C are in `content.rendered`.
- **Krungsri's 404 is a 444-byte iframe page** ("ขออภัย ไม่พบหน้าที่คุณค้นหา", HTTP 404). A trailing slash is enough to get past the WAF this month.
- **Lotus's segment pages carry each category's SMS code in a small banner** (`…-detailpro-2/3/4.webp`: `CDP11`, `CRS11`, `CGS11`); the separate SMS-number banner may 404.
- **Lotus's corporate notices are images** (`/announcement-corporate/…` → `/getattachment/<guid>/…detailpro.webp`): the fuel-coin exclusion was only in the image.
- **First Choice live vs dead code blocks**: the 11.11 codes are in visible HTML; old Payday codes (`KFVPAYDAY`) sit in HTML comments. An HTML→text pass that drops comments separates them.
- **Krungsri's PAY SAVE and Lotus's Pay Save are one campaign with two registrations** (`SAVE` → 081-927-9999 vs → 081-250-7777); check the sister company's site for a twin page whenever Krungsri Card launches a category campaign.
